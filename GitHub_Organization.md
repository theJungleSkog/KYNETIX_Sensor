# KYNETIX Sensor

| Folder | Contents |
| `firmware/` | Sensor code organized by technology (capacitive/FSR) and microcontroller (ESP32/nRF52840) |
| `data_acquisition/` | Scripts for collecting and exporting sensor data |
| `analysis/` | Sensor calibration, data processing, and validation |
| `visualization/` | Sensor heatmaps and visualization tools |
| `archive/` | Previous prototypes and historical code |

## Team Guidelines

- Develop new features on separate branches; use pull requests to merge into `main`.
- Use descriptive commit messages and filenames.
- Document hardware configurations and test results.
- Preserve previous firmware versions until they are verified as obsolete.
