Connection & sensor setup XIAO nRF52840 + 2× FDC1004 / V6 flex, five pads
1 / Prepare the device

Upload Kynetix_Flex5_XIAO_FDC1004_BLE_USB.ino with NUM_FDC = 2. FDC A: SDA → D4, SCL → D5. FDC B: SDA → D2, SCL → D3. Shield pins (SH) go to SHLD1, never GND. Power up with the insole unloaded for 2 s.

2 / Connect

Chrome or Edge. Connect Bluetooth → choose Kynetix Cap Insole. For USB, close the Arduino Serial Monitor first, then Connect USB. If Bluetooth is blocked when opening the file directly, serve the folder from localhost (e.g. python -m http.server).

3 / Check pads

Heel = flex S1 (pin 13) · lateral midfoot = S2 (pin 11) · 5th met = S3 (pin 8) · 1st met = S4 (pin 3) · big toe = S5 (pin 6). Press each pad and check that spot lights up. With one FDC1004 set FIVE_PADS = false in this file.

4 / Calibrate, then run

Shoe on and laced: Calibrate (lift 3 s, stand 5 s, lift and hold). Then press New run and start running. Use Zero any time a pad reads above 0 with the foot in the air.

5 / Reading the metrics

GCT is decided here from the pad values. Cadence, flight time and duty factor come from one foot and assume left/right symmetry. Flight time ≤ 0 means walking (no airborne phase), shown as “Walking”.

6 / Exports

Samples CSV = every sample as received (fF) with the contact flag decided here. Steps CSV = one row per step: GCT, stride, flight, duty factor, strike, and each pad’s peak (pF) and load timing.
